TAPAN RANJAN & SWARN LATA — WEDDING INVITATION WEBSITE

Open index.html in a browser to preview the invitation. Keep the assets folder beside index.html.
The song starts after the visitor taps “निमंत्रण खोलें” because mobile browsers block sound autoplay before a user gesture.

To publish and get a public shareable link:
1. Upload the complete tapan-swarnlata-wedding folder contents to a static hosting service such as Netlify Drop or GitHub Pages.
2. Make sure index.html is at the site root and the assets folder is uploaded too.
3. Share the generated public URL on WhatsApp.
